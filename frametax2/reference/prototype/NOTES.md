# FrameTax Prototype — Reference Archive

This directory contains the original single-file React prototype built as a Claude artifact.

## What it was
- Single-file JSX app (FrameTax.jsx) bundled via esbuild into a self-contained HTML
- All incentive math generated by Claude API calls — non-deterministic
- No backend, no database, no multi-tenant support
- Proof of concept for the UX and product direction

## What it proved
- The core value proposition: rebase BTL costs, apply local incentive, compute true net cost
- The user journey: upload budget → answer 12 questions → review parsed budget → see ranked destinations
- The UI design language (Cormorant Garamond / DM Mono / dark palette)

## What it could not do
- Deterministic, auditable calculations
- Source-backed rules with confidence tiers
- Multi-project / organization support
- Ingestion of real incentive PDFs
- Legal stacking validation
- Cultural test scoring
- BTL rate index with verified data

## What FrameTax 2.0 replaces
Everything except the UX design language, which will be adapted for the new frontend in a later phase.
