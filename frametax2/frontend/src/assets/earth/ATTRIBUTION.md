# Earth imagery (compact sidebar globe)

`blue-marble-1024.jpg` is a 1024x512 downscale of `earth-blue-marble.jpg` from the `three-globe` package examples
(`node_modules/three-globe/example/img/`), which is NASA Earth Observatory "Blue Marble" imagery. NASA imagery is
produced by a U.S. government agency and is not copyrighted; NASA asks for credit: **"Image: NASA Earth Observatory — Blue
Marble."** The `three-globe` code itself is MIT-licensed (Vasco Asturiano), which does not extend to the sample images.

Not used: the other `three-globe` example images and `clouds/clouds.png` (the example credits the clouds image to
github.com/turban/webgl-earth; its licence could not be confirmed from the repository, so the cloud layer is generated
procedurally instead). No remote imagery, no API keys, no network dependency: the file is bundled locally.
