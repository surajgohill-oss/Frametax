# Codex Historical Incentive Work Reconciliation

## Final gate

**CODEX_HISTORICAL_INCENTIVE_WORK_RECONCILED**

All 74 current P0 `CORE_PROGRAM_INCOMPLETE` programs and all 1,024 current residual fields were reconciled against retained Gemini, Codex, Claude and accepted project artifacts. No web research, implementation, database/rule mutation, optimizer work or test run was performed. Current canonical state is unchanged.

## Executive finding

Historical work is materially reusable but did not complete the current authority contract. 48 programs retain at least one current residual field resolved with identifiable primary authority; 26 retain useful assertions but no current residual field that meets the primary-authority closure standard. Across 1,024 residual fields, 257 are reusable with retained primary provenance, 297 were addressed but remain partial/conflicting/provenance-insufficient, and 470 were never historically resolved at the required field depth.

The historical phases optimized a **combination** of engine mechanics, coverage, authority research and executable encoding. Engine mechanics and broad coverage were genuinely completed. Primary-authority research and executable rules were completed selectively, while global closeout terminology often promoted source identification or program disposition into language that sounded like complete executable authority.

## Method and evidentiary rule

The comparison target is the live residual ledger generated by `canonical_residual_ledger.py`, not an old closeout's missing-field list. A field receives `HISTORICALLY_RESOLVED_WITH_PRIMARY_AUTHORITY` only where retained material identifies the controlling official/statutory source and the rule derived from it. An official URL in a separate profile does not automatically rehabilitate a rate asserted only by a secondary source. General QPE/local-spend language is partial unless it supplies the complete executable predicate. Bare closure labels never receive field credit.

The machine-readable artifact contains every current residual status/detail, exact historical classification, evidence summary and retained source reference. The rollup 'addressed but not currently reusable' combines provenance-insufficient, partial and conflicting fields; the exact five-way counts remain below and in JSON.

## What Gemini and Codex actually optimized

- **Engine mechanics:** yes. Mauritius/QPE doctrine, priceability gates, candidate generation, allocation/ranking and project acceptance paths received real validation or repair.

- **Program coverage:** yes. The work produced broad 285- and 415-record inventories plus distributed program dispositions.

- **Authority research:** partial. The five-jurisdiction controls and selected program profiles preserve substantive official-source work; many global records instead preserve secondary leads, generic source labels or a closeout assertion.

- **Executable rules:** partial. Real rate, spend-doctrine and requirements records entered runtime, but the current consolidation demonstrates that complete 14-dimension executable records were not published for the 74 P0 programs.

- **Project-specific pricing:** yes for accepted projects and the priceable subset. That validated calculations against available rules, not missing programs.

- **Global priceability:** partial. The system became safer by excluding authority-insufficient candidates; it did not make those underlying programs authority-complete.
