## Unresolved defects

### GW-001 — Overview optimizer QPE collapses to zero

**Severity:** P1 acceptance blocker (cross-surface economic contradiction)

**Affected projects and selected backend identities:**

| Project | Structure ID | Economic identity | Correct QPE | Overview QPE |
|---|---|---|---:|---:|
| The Little Utopia | `559a49ce-6581-4e78-ad8a-733f424e0b74` | `89f543279d132bcea03c6ce44cde857af6c5a31fdf369938392b36e469bbea05` | `$4,364,395` | `$0` |
| Bad Hombres | `da3b394b-152f-4637-a238-a9dcfa9e5eb2` | `bb142bd7a3805991ef3c6f1b0a480ca3aa5fc85d070f43de83a3bb70d24fa5a0` | `$2,482,023` | `$0` |
| F#K Valentine's Day | `dbcf5bda-a4af-4a70-a968-e4e6b19b0ce4` | `f8bced42ee725ccf7daf4196b7bbaea53b4b111f5b30513a267e2f77440ed69a` | `$4,517,687` | `$0` |
| Lips Like Sugar | `601a8a8f-d1b0-42f1-8aef-5934e0422502` | `1e6c80a564510dde3c2fea3cd99b21a5625c63c1ffcb6cb6d5cc3ef6bdd71d02` | `$11,983,654` | `$0` |

**Runtime reproduction:** open any affected production's Overview, locate `Project Globe` -> `Top Structures` -> `OPTIMIZED`, and compare its `Qualified Spend` with the same structure in Workspace or its Inspector. The Overview value is `0`; Workspace/Inspector show the QPE above.

**Localized cause:** `frontend/src/lib/productionOptions.js:qpeOf()` sums only `structure.segments[].qpe_usd`. These canonical hybrid optimizer structures have `segments=[]` and carry their real routed QPE in `component_allocations[].allocated_usd`. Workspace already implements that fallback; Overview's shared card helper does not.

No other unresolved acceptance defect was reproduced.
