## 4. Hierarchical Subnational Resolution Engine

Replace `get_profile_or_fallback` in `location_cost_benchmarks.py` with hierarchical resolution:

```python
def get_profile_or_fallback(iso2: str) -> JurisdictionCostProfile:
    """
    Hierarchical jurisdiction lookup:
    1. Exact match (subnational e.g. 'US-CA', 'CA-BC', 'AU-NSW', 'ES-CN')
    2. Parent fallback (split '-' to check 'US', 'CA', 'AU', 'ES')
    3. Baseline fallback (Los Angeles baseline 'US-CA' with LOW confidence)
    """
    normalized_key = (iso2 or "").strip().upper()
    
    # 1. Exact match in 121 profiles
    if normalized_key in BENCHMARK_PROFILES:
        return BENCHMARK_PROFILES[normalized_key]
        
    # 2. Subnational parent fallback
    if "-" in normalized_key:
        parent_key = normalized_key.split("-")[0]
        if parent_key in BENCHMARK_PROFILES:
            parent_profile = BENCHMARK_PROFILES[parent_key]
            # Inherit parent with provenance tag
            return dataclasses.replace(
                parent_profile,
                iso2=normalized_key,
                name=f"{normalized_key} (Inherited from {parent_profile.name})",
                confidence="MEDIUM",
                notes=f"Subnational code {normalized_key} inherited from national parent {parent_key}."
            )
            
    # 3. Global LA Baseline Fallback
    baseline = BENCHMARK_PROFILES.get("US-CA") or BENCHMARK_PROFILES.get("US")
    return dataclasses.replace(
        baseline,
        iso2=normalized_key,
        name=f"{normalized_key} (Default Baseline)",
        confidence="LOW",
        notes=f"Unknown jurisdiction {normalized_key}; defaulting to Los Angeles baseline."
    )
```

## 9. Guardrails Against Double Counting

1. **Travel / Accommodation / Per Diem**: Already owned by the canonical travel/FX engine in `canonical_travel.py`. The BTL normalization engine must strictly exclude ATL travel, business-class flights, and hotel bookings from the BTL index.
2. **Post-Production & VFX**: Post-production, music, and visual effects are routed through separate component incentive routing (`canonical_component_routing.py`). Do not apply BTL production crew location indices to post/VFX.
